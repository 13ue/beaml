Generated REPLAY RUN

One BEAML source generates the flow, the HTTP EFFECT, the decode, the CAPTURE and the REPLAY RUN. Since slice 2 the compiler also knows the TYPE VERSION of every stored record.

The goal: vertical integration

OWNER statement (DL-020): BEAML owns the whole path from source to production, so that agents make fewer errors. One language and one compiler know every stage.

What the compiler must own

  • Rust-level diagnostics, fast builds
  • Types at runtime; no any, no casts
  • Typed errors, analysed failures
  • Built-in tests and evals
  • Typed traces, alerts, flags

Applied to stored data

  • Compiler knows stored TYPE VERSIONS (DL-021)
  • History as a migrate chain (DL-022)
  • No guessing fallback (DL-028)
  • Deploy blocks only without a path (DL-031)
