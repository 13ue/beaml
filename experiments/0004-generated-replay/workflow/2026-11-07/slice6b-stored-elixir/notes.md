Elixir starts only when all of these are absent and `calls` is not empty (D6B-105, RED review O3). Each `error F` verdict goes into `faults` as `Some(F)`, so the DL-102 block text stays byte-equal.
- `ctor_fault` removed; `ctor_pick` (new) gives the first matching signature and its inputs, or None (no signature). The static clause-body decision is gone (D6B-104). A call is added only when the signature has a failure TYPE. The `ponytail:` comment names the Rust mirror of the `cond` in `__beaml_from_T` (D6B-103) and the upgrade path.
- `DRIVER` (new const): the Elixir driver text below.
- `run_elixir` (new): reads `BEAML_STORED_ELIXIR_LIMIT_S` (default 60; a value that is not a whole number from 1 is a build error), spawns `elixir -e DRIVER` with piped stdin, stdout and stderr, `process_group(0)` and `ERL_CRASH_DUMP=/dev/null`. One worker thread writes stdin, drops it and calls `wait_with_output`; the main thread calls `recv_timeout(limit)`. On expiry: `/bin/kill -KILL -- -<pid>` and the run error `(time limit N s)`. Spawn `NotFound` gives the D6B-106 text with event `ms: 0`. Child output is never forwarded. One `stored-elixir` event per run: `result` ok, blocked or error; `ms`; `calls`.
- `parse_elixir_results` (new, D6B-121): success needs `status.success()`, exactly K lines, each `ok` or `error F` with F in the failure list of that call. Else `exit N`, `signal N` or `result lines`.
- Unit test `elixir_results_are_strict` (U1): good lines; one line short; one extra; `okay`; `error` without F; `error Other`; exit 1; signal 9. It also asserts that `DRIVER` starts with the marker line and holds no `rescue`, `catch` or `try` (RED review O1).

### The driver text

```elixir
# beaml-stored-check
%{"module" => module, "calls" => calls} = JSON.decode!(IO.binread(:stdio, :eof))
Code.compile_string(module)

for [fun, type, args] <- calls do
  ok = Module.concat(BeamlSpike, type)

  case apply(BeamlSpike, String.to_atom(fun), args) do
    {:ok, %{__struct__: ^ok}} ->
      IO.puts("ok")

    {:error, %{__struct__: failure}} ->
      ["BeamlSpike", name] = Module.split(failure)
      IO.puts("error " <> name)
  end
end
```

Stdin: `{"module": <code>, "calls": [[new_T_k, T, [inputs]], ...]}`, written with `json_string`.
