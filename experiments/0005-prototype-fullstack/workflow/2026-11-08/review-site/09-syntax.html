CTOR-ROW Konstruktor-Feld in einer Zeile: erste Signatur nimmt genau die String-Felder Default, gebaut

Der Encoder schreibt die Struct-Felder, der Decoder liest die erste passende Signatur. Jede andere erste Signatur wäre nicht rücklesbar: Build-Fehler.

type Amount { value: String currency: String }
fn Amount value: String, currency: String -> Amount ! BadAmount
// Die erste Signatur muss genau value und currency nehmen.
  1. Adiese Regelgebaut
  2. Bnach Signaturnamen kodieren
  3. Cerlauben und Zeilen verlieren
