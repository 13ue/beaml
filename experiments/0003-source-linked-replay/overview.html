Owner decisions

Decided

  • Run the repair test with --source-run (option B)
  • Retain both responses, not only the first
  • No timestamp in the record; time comes from the trace
  • Non-canonical body test (A1) in gate 4
  • No replay branch in the router
  • No HTTP 502; typed errors
  • Check the response digest
  • Replay as a separate runner (option A)
  • Claude reviews RED, a fresh agent double-checks

Open

  • D002: Which code belongs to the artifact hash? Today only the BEAML part, not decode
  • D003: With trace sampling, a record can lose its time reference
  • Roast objection 4: Is a host runner enough, or does replay belong in the language?
