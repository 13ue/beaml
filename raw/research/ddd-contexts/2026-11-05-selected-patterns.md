## Transferable patterns

- A BOUNDED CONTEXT defines a consistent model meaning. A service, layer, crate or application is not automatically that boundary.
- A context map should show semantic influence and translation. It should not pretend to specify deployment topology.
- One glossary file can hold context-qualified homonyms. Shared spelling need not mean shared semantics or one shared runtime struct.
- Keep shared definitions small. Give each a definition, scope, owner, aliases, limits and an owning interface or artifact.
- Agent-facing vocabulary still needs review. A glossary does not prove compiler results, runtime safety or measured agent improvement.
- An ANTI-CORRUPTION LAYER translates a foreign model into a receiving model. Adopting the transport format unchanged is not the same thing.
