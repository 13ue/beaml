- Rust compiler validate.rs checks phase-aware CFG/type/debug-info invariants. MIR-opt README documents pass-specific dumps/diffs and platform bit widths. UI docs describe manually reviewed blessed stderr/stdout snapshots. These check structure/regressions, not a theorem that a pass preserves all observations.
- BAML optimize.rs runs CFG/dead-store/local/copy cleanup, constants at O2 and verifier checks in debug. Emitter verifier checks dense block IDs, redirect termination and unreachable defaults for exhaustive switches. Its type_spec harness checks annotated inferred types and diagnostics; fixture assertions were inspected, not executed.
- Proptest Strategy creates ValueTree; current/simplify/complicate couple generation and shrinking. Range strategies retain their domain during shrink. Filtering can cause local/global rejection, expensive generation and blocked shrinking paths. TestError distinguishes Abort from a failing counterexample; rejection-budget exhaustion is not success.
- Proptest state-machine implementation has reference init/transitions/apply/preconditions and SUT apply/invariant hooks. Sequential strategy rechecks preconditions during generation/shrink. Removing a prior transition may invalidate later inputs, so the original generated sequence's validity is insufficient. Initial state, transition deletion and transition data have separate shrinking operations. No concurrent strategy guarantee inferred.
- Failure persistence stores seeds, not arbitrary serialized input values. A changed generator can yield another valid input from the same seed; retain concrete minimized counterexamples plus generator/compiler/environment identity for robust replay.
- LLVM libFuzzer is in-process coverage-guided mutation with SanitizerCoverage, a callable target, saved corpus and crash/timeout artifacts. Targets should be deterministic and tolerate repeated calls; seed valid and invalid structured examples. Corpus replay and merging/minimization are distinct from random-run count. Docs report maintenance-only major-development status; no tool selection follows from this note.
- NIST mean CI guidance distinguishes the statistic/interval method and repeated-sample interpretation. A mean's t interval is not a latency p95 interval. Bootstrap resampling estimates statistic uncertainty but is not suitable for every distribution/tail statistic. BEAML's baseline 30-run minimum does not make p99 reliable; tail sample count is sparse.
